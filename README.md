# דופק

אפליקציה אישית שמראה מה קורה בישראל בכלכלה, בדמוגרפיה, בעסקאות, במחקרים, בכנסת ובחוקים חדשים, ושולחת פושים על כל דבר חשוב.

- `index.html`: האפליקציה (PWA, אפשר להתקין למסך הבית)
- `scripts/fetch.mjs`: סורק כותרות ושולח פושים (רץ כל 30 דק' ב-GitHub Actions)
- `scripts/sources.mjs`: רשימת המקורות ומילות המפתח. כאן משנים מקורות ונושאים.
- `DOFEK_TASK.md`: ההוראות ל-Claude (סיכומים וניתוחי עומק כל 3 שעות, כללי ניטרליות)
- `icons/cards/`: תמונות הפושים לכל נושא
- `config.json`: ערוץ הפושים, שעות שקט ומספר פושים מקסימלי לכל ריצה
